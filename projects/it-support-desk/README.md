# IT Support Desk

An internal help desk for a small company. Employees need a clear way to report an IT issue and follow its progress; support agents need a shared queue to triage, assign, and resolve it. The product's center is the ticket lifecycle, not service discovery or appointment booking.

**Portfolio position:** Second selected POC, after Salon Booking.

**Phase:** Product discovery. Frontend-only Base44 prototype with deterministic dummy data is planned; no prototype has been generated or reviewed.

**Next decision:** Review the prototype formatting defaults, route plan, and design direction before using the Base44 foundation prompt. See the [current shared workflow](../../shared/workflow/workflow.md).
