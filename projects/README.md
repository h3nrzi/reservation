# Project documentation

Each active POC gets one directory named with a stable, lowercase slug, for example `projects/carcare/`. Do not create empty directories for ideas that are still only in the [catalog](../portfolio/project-catalog.md).

Start each directory with a `README.md` containing:

- Product name and the problem that makes it distinct in the portfolio
- Current phase and next documented decision
- Links to the current product brief and other key documents
- Code repository, prototype, or demo links when available

Add folders only when needed. Use `docs/product/`, `docs/design/`, `docs/pages/`, `docs/architecture/`, `docs/decisions/`, and `prompts/` as applicable. Keep drafts and versioned documents with the product they describe. Shared methods and rules belong in [`shared/`](../shared/workflow/README.md).
