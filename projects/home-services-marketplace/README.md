# Home Services Marketplace

A Persian-first marketplace where a customer describes a household problem, receives comparable provider quotes, and assigns a job. The product centers on **request → matching → quote → assignment → job progress**, not appointment booking.

**Workflow:** [v0.2](../../shared/workflow/workflow-v0.2.md)

**Phase:** Product discovery and Base44 prototype preparation

**Base44 project:** Not created yet

## Prototype checkpoint

Foundation, Home, and New Request are the first three Base44 passes. Stop after each pass to review product structure and log non-blocking UI debt. The current Salon Booking checkpoint consists of a foundation plus two reviewed public pages; this project aims for the equivalent checkpoint before spending beyond the initial Base44 credit.
