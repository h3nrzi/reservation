# Service POC catalog

Salon Booking is the existing project. The ten candidates below were chosen for different product problems and workflows, not merely different service categories. None has been selected as the next POC yet.

| Candidate | Distinct product problem |
| --- | --- |
| Home Services Marketplace | Match customers with providers, quotes, and assignments |
| CarCare | Vehicle-centered service history and maintenance lifecycle |
| Property Management | Property, tenant, maintenance, and contractor operations |
| Moving Platform | Inventory, estimates, scheduling, and logistics |
| IT Support Desk | Ticket triage, assignment, and SLA workflow |
| Field Service Management | Technician dispatch, routes, and work orders |
| Event Planning Marketplace | Multi-vendor planning, budget, and event workspace |
| Creative Services Platform | Briefs, proposals, milestones, and deliverables |
| Renovation Management | Long-running phases, contractors, costs, and progress |
| Local Delivery Platform | Pickup, driver assignment, tracking, and delivery lifecycle |

Selection should record the chosen project's distinct problem, initial POC boundary, and why it adds something new to the portfolio. Create its directory under [`projects/`](../projects/README.md) only after selection.
