# Shared workflow

The [Controlled Vibe Coding Workflow v0.1](workflow-v0.1.md) is the current cross-project baseline. Its status remains **Draft / In Use**. Apply it to each POC while allowing project-specific choices to live with that project.

The [feedback log](workflow-feedback.md) records observations from real projects and candidates for a later version. Entries from Salon Booking are evidence for improving the shared process, not separate Salon Booking requirements.

When the workflow changes, create a new version and update this index. Do not silently rewrite a version that projects have already used.
